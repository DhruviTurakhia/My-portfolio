# Dhruvi Turakhia — Portfolio

Personal portfolio for [Dhruvi Turakhia](https://github.com/DhruviTurakhia), a senior software
engineer focused on backend systems, APIs, databases, and product engineering.

## What the site highlights

- 4+ years building software across fintech and healthcare
- 32+ production REST APIs delivered as a founding backend engineer
- 40% database-query performance improvement
- Leadership experience with 14+ backend engineers
- Kirana Ops Agent, an AI-enabled operations project for Indian shop owners

## Built with

The site uses semantic HTML, modern CSS, and a small amount of vanilla JavaScript. It has no
framework or runtime dependency, which keeps it fast and makes deployment through GitHub Pages
straightforward.

## Run locally

Open `index.html` directly, or serve the folder with any static file server.
